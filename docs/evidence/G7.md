3. **Décisions** : nom de production et HSTS, ouverture du module hors ligne, propriété du code source, indexation du showroom, délais de support (Q14), jalons commerciaux (Q15).
4. **Matériel** : impression réelle et appareils du cabinet (`docs/evidence/usability.md`).
5. **Procès-verbal final** signé par la cliente (modèle dans `docs/evidence/delivery-final.md`).

Aucun de ces points n'est un défaut du code livré ; ce sont ceux que ni le prestataire ni les tests ne peuvent fermer seuls.
